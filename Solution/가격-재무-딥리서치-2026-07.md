## 0. 한 줄 결론 (덱에 미치는 영향)

1. **🚩 take-rate 앵커 하향 필요:** FinOps 툴 실측 take-rate는 **0.5~2%**에 몰림. 우리가 쓰던 "2~3%"는 **상한값(upper bound)**이지 시장 중앙값이 아님. → 덱·TAM 렌즈A를 **"1~2%(범위 0.75~3%)"**로 교정. Q&A 방어력 ↑.
2. **✅ ACV $30K = 실증 방어됨:** 옵저버빌리티 툴($5~25K)보다 위, 클라우드 FinOps 툴($30~130K)보다 아래 → mid-market 블렌디드 $30K는 comps 한복판. 유지.
3. **⚠️ NRR 110~120% = 상위 25% 목표치:** 중앙값 아님. SaaS Capital: ACV $100K+ 상위 25%가 118~120%. → 덱엔 "110% = 상위 사분위 목표"로 정직하게 프레임.
4. **⚠️ 3년 ARR 램프($0.24M→$1.35M→$4.8M) = 신뢰 가능하나 공격적:** Y1→Y2 5.6배, Y2→Y3 3.6배 = "강한 실행 시나리오"지 보수적 기준선 아님. 피치용으론 OK, 단 고객 수로 sanity check 병기.
5. **✅ per-agent 과금 = 선례 존재:** Agentforce($2/건·$5~550/user)·Datadog(호스트당)·아웃컴 과금($2/resolution) = 비-토큰 과금 정착. per-agent = seat형이라 NRR 예측 가능성 ↑ → 우리 BM 서사 보강.

## 2. take-rate 방어 (렌즈A 교정)

- **덱/TAM 기존:** "관리 AI 지출 × 2~3% take-rate."
- **실측 발견:** FinOps take-rate = **0.75~3% 스펙트럼, 실거래 중앙 0.5~2%.** 2~3%는 소규모 지출 구간·상한에서만.
- **✅ 교정 권고:** 렌즈A 기본값 **2% → 1.5%(범위 1~2%)**, "FinOps 실측(Cloudability 공식 0.75~3%·CloudZero 실거래 0.5~1%·Finout ~1%)로 방어" 표기.
- **효과:** "왜 2~3%냐" 반론에 "실은 우리는 take-rate로 과금하지 않는다(per-agent). take-rate는 시장 크기 sanity check용이고, 보수적으로 1~2%를 쓴다"로 오히려 강해짐.
- **TAM 영향:** 렌즈A 미드포인트가 대략 절반으로 하향(2.5%→1.5%). TAM $0.7~2.5B → **$0.5~1.8B(2026)** 근방으로 조정 권고. 단 렌즈B(직접 카테고리 $0.7~1.1B)와 여전히 수렴 → 스토리 불변, 숫자만 보수화.

## 3. NRR 벤치마크

| 소스 | 세그먼트 | NRR |
|---|---|---|
| SaaS Capital 2023 | ACV $25K+ 중앙값 | **≥103%** |
| SaaS Capital 2023 | ACV $100K+ 상위 25% | **118~120%** |
| ChartMogul | $1~3M ARR 상위 25% | 94% |
| ChartMogul | $3~15M ARR 상위 25% | 99% |
| ChartMogul (신) | B2B SaaS 중앙값 / 상위 25% | 82% / 97% |

- **판정:** **110~120% = 상위 사분위, 중앙값 아님.** 초기 인프라 SaaS 중앙값은 오히려 100% 밑도 흔함(AI 처른 웨이브).
- **✅ 덱 권고:** NRR **110%를 "목표/상위 사분위 시나리오"로** 명시. per-agent 확장(20→40→80) 서사가 이 목표를 정당화하되, "달성 목표지 현 실적 아님" 정직 표기. 120%는 쓰지 말 것(상한 과장).

## 4. 3년 ARR 램프

- **덱 곡선:** Y1 ~$0.24M → Y2 ~$1.35M → Y3 ~$4.8M. (Y1→Y2 **5.6배**, Y2→Y3 **3.6배**.)
- **판정:** **신뢰 가능하나 공격적**(보수 기준선 아님, "강한 실행 케이스"). ChartMogul: sub-$300K→$1M+ 이행기엔 이 속도 관측되나 상위 실행에 한함.
- **고객 수 sanity check (ACV $30K 기준):** Y1 **8곳** → Y2 **45곳** → Y3 **160곳**. (ACV $20K면 Y3 240곳.) → 신규 로고만으론 빠듯, **확장(NRR)이 필수 동력**임을 곡선이 전제.
- **✅ 덱 권고:** 곡선 유지(피치는 강한 케이스 제시가 정상), 단 슬라이드에 **고객 수 + NRR 동력**을 병기해 "숫자 근거 있음"을 증명. "보수 기준선은 더 낮다" 한 줄로 Q&A 방어.
