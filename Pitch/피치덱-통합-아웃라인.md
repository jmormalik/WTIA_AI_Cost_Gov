## [2] The Shift — 지출 결정권의 이동

**헤드라인:** "AI 지출을 결정하는 주체가 사람에서 모델로 넘어갔다."

**슬라이드 카피:**
- 전통 SW: 비용은 개발자가 코드에 명시 → 예측·통제 가능.
- 에이전틱 AI: **모델이 스스로** 어떤 툴을 언제 몇 번 부를지 결정 → 지출 방아쇠가 모델로.
- 프로덕션 에이전트 토큰 소모 = 챗봇의 ~50배. 재무는 통제권을 잃었다.

🎤 발표 노트: 이게 전체 덱의 축. "우리 회사 문제"가 아니라 "카테고리 전체가 지금 겪는 구조 변화"로 프레임.
🔵 토큰 50배 = 업계 추정.

## [3] The Villain — 사후 대시보드·정적 키

**헤드라인:** "지금 도구들은 불이 난 뒤에 CCTV를 돌려본다."

**슬라이드 카피:**
- 관측 도구(대시보드·빌링)는 **월 단위·사후**. 이미 나간 돈만 보여줌.
- 정적 API 키·고정 상한(max_iterations)은 무딘 칼 — 정상/폭주 구분 못 함.
- 결정적: 총액은 로깅·빌링에 이미 보인다 — 못 하는 건 **감사등급 분해**다. LLM 호출까지만 귀속되고, 에이전트가 부르는 **검색·크롤링·서드파티 API는 유발 에이전트에 안 붙어** 흩어짐 → 고객·기능 단위 원가를 아무도 감사등급으로 분해 못 함.

🎤 발표 노트(경쟁 정직성): LiteLLM·Portkey는 LLM 예산 상한이 이미 성숙. 우리가 치는 갭은 그 위 — "기능이 있다 ≠ 조직이 원가를 예측·귀속·설명한다."

## [4] 진짜 통증 — 증거 + 재정의

**헤드라인:** "문제는 '얼마 나갈지 모른다'가 아니다. '왜 나갔는지 설명 못 한다'는 것이다."

**슬라이드 카피 (전 규모 실사고 밴드):**
- 개발자 1인, 무한 재시도 루프 → **11일간 인지 못한 채 $47K** 청구.
- B2B SaaS, 하룻밤 API 사용량 **400% 급증**.
- 대기업 규모에선 통제 실패가 연 수억~수십억 달러.
- **재정의:** 급증은 계기일 뿐. 진짜 손실은 사고 후에도 "고객 1명당 AI 원가·어느 기능이 마진 먹는지" 답 못 하는 것 → 가격 책정·이사회·실사에 매달 필요한 **상시 니즈**.

🎤 발표 노트: "지속가능 AI SaaS 기준선 = LLM 비용 < COGS 20%. 이 선을 아는지조차 대부분 모른다." ✅ 사고 사례는 why-now.md 출처.

## [6] Vehicle — 솔루션

**헤드라인:** "실행 경로 위에서 원가를 귀속·통제하는 레이어."

**슬라이드 카피:**
- 사후 대시보드(경로 밖) ❌ → 실행 경로에서 LLM+툴+외부 API 호출을 요청 단계에 귀속·통제.
- "불 난 뒤 CCTV가 아니라 불붙기 전 차단기" — 실행 전 차단 + **왜 막았는지 감사등급 설명**.
- **신뢰 사다리로 진입:** 1단 경로 밖 리포트(프록시 없음) → 2단 비동기 정책 → 3단 고객 소유 게이트웨이 차단. (우리는 경로를 소유하지 않는다.)

🎤 발표 노트: 신뢰 사다리 = 리스크 대책. "critical path엔 OSS만" 신호를 정면 반영. 팀 확정(7/23).

## [8] Customer — 누가 산다

**헤드라인:** "지금 닿는 AI-native 스케일업에 팔고, 못 만드는 비 AI-native 물결을 탄다."

**슬라이드 카피:**
- **비치헤드(지금 유료): AI-native 스케일업 B2B** — 월 AI 지출 **$50K~$500K**, 50~300명, Series A~C, 툴/외부 API 비중 高. **자기 실행 경로를 소유** → 우리 실행 전 통제층이 붙고, 디자인 파트너로 도달 가능.
- **왜 여기서 시작:** 모의 인터뷰·데모·유일 실신호(AI 검색사 ML 리드)가 전부 여기를 가리키고, **제품이 끝에서 끝까지 정합**한 유일한 세그먼트.
- **확장 물결: 비 AI-native 중견기업**(AX 전환 — 운송·물류·제조·금융, 월 $100K+, 벤더 3개+). **AI 엔지니어링 DNA 없어 구조적으로 못 만듦** → "직접 만들지" 반론이 여기서 소멸, 모집단은 AI-native를 압도.
- **구매자 = CTO(경제적)**, 챔피언 = AI/데이터 운영 리드, 영향자 = CFO. 고객단위 COGS = B2B 니즈(고객=계약). **한국 AI 스타트업 = 무료 디자인 파트너.**

🎤 발표 노트: **A 주도 블렌드(CEO 결정 8/3)** — 지금은 닿는 AI-native 스케일업에 팔고, 비 AI-native 물결을 확장으로 탄다. "토큰 사고 말지"($50K+ 지출)·"직접 만들지" 둘 다 선제 방어 — AI-native 답 = buy-vs-build ROI + 크로스벤더 + 감사등급 + 복제 불가 벤치마크 데이터, 그리고 비 AI-native로 확장하며 반론이 구조적으로 죽음. ⚠️ 지출 임계·구매자·비 AI-native "못 만든다" = 인터뷰 검증 대상.

## [9] Market — TAM/SAM/SOM

**헤드라인:** "비치헤드 = 닿는 AI-native 스케일업. 기울기 = 못 만드는 비 AI-native 물결. 크기가 아니라 기울기에 베팅."

**슬라이드 카피:**
- **TAM** ≈ **$0.5~1.5B (2026)** → **$2~6B (2030)** — 엔터프라이즈 GenAI 지출 $50~60B의 1~2%(탑다운·세그먼트 불가지론, FinOps take-rate 실측 앵커). CAGR ~20%.
- **SAM** ≈ **$0.24~0.45B (2026)** → **$0.8~1.8B (2030)** — ICP 부합 기업 × ACV $30K: **지금은 AI-native 스케일업, 확장하며 비 AI-native 중견기업 합류.**
- **SOM(3년)** ≈ **$1.0~3.6M ARR** — 닿는 AI-native 비치헤드(한국 디자인 파트너 → 미국 유료), 비 AI-native 인접으로 확장.

🎤 발표 노트: **A 주도 블렌드 — 근시 SOM = 닿는 AI-native 스케일업(증거+제품 정합성), 기울기 = 훨씬 큰 비 AI-native 물결**(채택 곡선 이제 막 시작 → 2030년 3~4배, 못 만드니 우리 몫). ⚠️ 옛 LAM $80K 절대 제시 금지. 종량(take-rate)으로 과금 안 함 — 시장 sizing sanity check용. 🔵 `Market/TAM-SAM-SOM.md`(2026-08-03 재산정).

## [10] Competition

**헤드라인:** "시장의 단층선 = 사후 관측 vs 실행 전 통제. 우리는 그 위에 'COGS 설명'을 얹는다."

**슬라이드 카피 (4개 레이어):**
- **직접:** SatGate("Economic Firewall") — 문제·형태 거의 동일하나 **프리론칭**(아무도 시장 못 잡음 = 속도 게임).
- **관측성(간접):** Langfuse·Helicone·LangSmith — 추적O 통제X(사후).
- **FinOps(간접):** CloudZero·Vantage·Finout — 사후 재무 귀속, 실시간 통제X.
- **Status quo(진짜 경쟁):** 로그 뒤지기·스크립트·하드캡 — 구조적으로 불가능한 걸 우리가 함.

🎤 발표 노트: SatGate 존재 = 양날(문제 실존 검증 + 속도 관건). 우리 자리 = "실행 전 통제 × COGS 설명" 사분면(재무·인텔리전스 레이어)은 아무도 안 함.

## [12] Moat

**헤드라인:** "따라잡히는 건 기능이다. 따라잡을 수 없는 건 데이터다."

**슬라이드 카피:**
- 캐싱·라우팅·하드리밋 = 6개월이면 복제. 해자 아님.
- 해자 = 고객 데이터가 쌓일수록 강해지는 것:
  1. **유닛 이코노믹스 정확도 격차** — 트래픽 쌓일수록 폭주 감지·비용 시뮬레이션 정확. 후발주자는 데이터 0에서 시작.
  2. **동종 벤치마크(후행)** — "같은 유형 대비 요청당 원가 상위 20%". 고객 수 비례, 후발 구조적 불가.
- 이 원가 뷰가 **가격·이사회 루틴에 박히면 전환비용 급등**.

🎤 발표 노트: 시간축 — 진입(크레딧 카운트다운 무료 쐐기) → 차별화(유닛이코노믹스+단가 카탈로그) → moat(시뮬 정확도+벤치마크).

## [13] BM / Pricing

**헤드라인:** "원가를 파는 회사는, 고객의 원가에 비례해 벌지 않는다."

**슬라이드 카피:**
- 지출액 비례 과금 ❌(절감 인센티브와 충돌). **감시 에이전트 수(per-agent)** 로 과금 → 인센티브 정렬. (API 호출 수 아님·지출액 아님.)
- **정의(Q&A 방어):** 감시 에이전트 1개 = 프로덕션에 배포된 1개 AI 기능 파이프라인(예: 검색봇·요약·온보딩봇). Datadog per-host / APM per-service와 동일 개념 → "트래픽 튀면 청구서 튀나요?" 반론 무력화.
- 3단: **Free**(모니터링·차단=커모디티) → **Growth**(자동 COGS 리포트=유료 시작점) → **Enterprise**(감사등급+경로 내 차단).
- 확장 = 에이전트 20→40→80 늘수록 매출↑ = **net-negative churn**.
- 슬로건: "차단기를 팔기 전에 장부부터."

🎤 발표 노트: "정액이냐 종량이냐" 질문 → "구독 기반, 단 종량 축은 지출이 아니라 에이전트 수." 상세 카피·가격 카드 = [슬라이드-BM-가격.md](슬라이드-BM-가격.md). ⚠️ 가격 숫자는 가설(앵커: 지출 2~3%, CloudZero 실증).

## [14] GTM

**헤드라인:** "챔피언이 무료로 물고, CTO가 COGS 때문에 지갑을 연다."

**슬라이드 카피:**
- **랜딩:** 무료 Cost Autopsy 리포트(경로 밖) → AI-native 스케일업의 AI/엔지니어링 리드가 bottom-up 도입.
- **전환:** 사고 or 크레딧 소진 시점에 챔피언이 CTO에게 유료 제안 → COGS·마진 리포트로 밀착.
- **시장 순서:** 한국 AI 스타트업(무료 디자인 파트너·검증) → 미국 **AI-native 스케일업(유료 비치헤드)** → **비 AI-native 중견기업 확장(운송·물류 우선)**.
- **Blocker 선제:** IT/법무엔 "메타데이터만 수집 + 크로스벤더 독립 감사."

🎤 발표 노트: 신뢰 사다리 1→2→3단이 그대로 GTM 확장 경로. 비치헤드 = 닿는 AI-native 스케일업(증거+제품 정합성), 비 AI-native 중견기업(운송·물류 우선)은 "직접 만들지"가 죽는 확장 구간. 이해관계자 맵 액션플랜 기반.

## [15] Traction

**헤드라인:** "허수 지표 대신 고객개발: 실제 스크리닝 2건 + 페르소나 인터뷰 5건 — 그리고 그게 쐐기를 어떻게 좁혔나."

**슬라이드 카피:**
- **실제 외부 스크리닝 2건(비동기 링크드인):** 한국 AI 검색 스케일업 Lead ML Eng(2라운드) — build/buy가 비용 구조를 가르고, 고객단위 귀속엔 별도 데이터 작업 필요 = **우리 쐐기 방증**. 미국 시드 에이전틱 플랫폼 창업자(2라운드) — 설계상 anti-ICP(PMF 전·성장 우선) → **ICP 하한을 날카롭게** 함.
- **구조화 페르소나 인터뷰 5건(Mom-Test 가이드 × 리서치된 Buyer Persona):** H0(툴/외부 API 비중 ≥15%) 생존 2/5·결측 1·부정 1(6%)·탈락 1(B2C). **"LiteLLM은 외부 API 귀속 못 함" 독립 사례 2건** 확보.
- **"탈락 데이터"도 자산** — anti-ICP 스크리닝(위 시드 창업자·B2C 앱)조차 ICP를 날카롭게. 파는 방식 = 아무에게나 안 판다.
- 아웃리치 진행(한국 AI 스타트업 · 미국 Top 5) — **디자인 파트너 소개가 곧 우리의 Ask**(마지막 슬라이드와 연결).
- **목표 지표 = net-negative churn**(에이전트 확장).

🎤 발표 노트: **Q&A 정직성** — 실제 비동기 스크리닝 2건 + 페르소나 기반 검증 5건(리서치 페르소나 대상 롤플레이) = 7개 접점, **정식 라이브 인터뷰는 0건.** "5건 실제 사람이었나?" 물으면 정면으로: "라이브 아웃리치 전에 Mom-Test 가이드로 H0·반론을 사전 검증한 페르소나 드라이런." **라이브 고객처럼 암시 금지.** 프레임 = 쐐기를 증거 위에 세우는 중. **기밀: 두 스크리닝 대상 실명은 이 파일/덱(공개)엔 익명, 무대 구두·로컬 원자료로만** (7/23 기밀 규칙).

| 반론 | 답 |
|---|---|
| "그냥 토큰 사고 말지?" | 소규모엔 맞음. 그래서 비치헤드는 월 $50K+ 지출·툴/외부 API 비중 高 AI-native 스케일업 — 잘못 매긴 가격 하나가 도구값보다 훨씬 큼. |

| "지출%로 과금 = 절감액 연동 아냐?" | 지출액 아님. 관리 에이전트 *개수* 기준. 지출 2배로 뛰어도 우리 청구는 그대로. |
