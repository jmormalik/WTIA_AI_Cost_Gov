### Kyber 포지셔닝에 주는 의미

**1. "총액은 보여도 분해가 안 된다"가 실제 pain으로 확인**
Langfuse로 LLM 토큰은 보이나 외부 API(판례 검색·OCR·임베딩)는 별도 대시보드에 흩어져 있고, 통합은 수작업 엑셀로만 가능하다는 발언이 가설 2를 직접 실증한다. 이는 라이너 2차 회신 인사이트("기능·팀·고객별 분해는 별도 파이프라인 비용 필요")와 정합하며, 피치 슬라이드 Villain 워딩 "총액은 로깅·빌링에 이미 보인다 → 못 하는 건 고객·기능 단위 감사등급 분해"를 실제 발화로 뒷받침하는 첫 사례다.

**2. LLM 외 외부 API가 35%라는 구체 수치 확보**
가설 0의 수치 근거가 처음으로 실제 인터뷰(모의)에서 나왔다. 법률 AI처럼 판례 검색·OCR·임베딩이 묶인 세그먼트에서 외부 API 비중 35%는 데모 Tab1의 "41% 비-LLM" 설명과 오더-오브-매그니튜드로 일치한다.

**3. $6,200/주말 사건 = 피치 인시던트 슬라이드의 구체 예시 후보**
Why Now 슬라이드 또는 Villain 슬라이드에서 "$47K/11일 루프", "$4.2K 개발자 단독" 사례와 같은 층에 넣을 수 있는 국내 law-tech 사례 구조다. 실제 인터뷰에서 동등한 사례를 확보하면 즉시 사용 가능.

**4. rate limiter 자체 구축 = "자체 구축 선호" 반론 약화 증거**
엔지니어 1명 1주를 써서 rate limiter를 만들었으나 — OCR·임베딩 쪽에는 아직 못 붙였고, 금액 기준 사전 차단은 "어떻게 자동화하는지 몰라서 안 하고 있다"는 발언이 나왔다. 자체 구축이 불완전하고 유지보수 부담이 쌓이는 패턴 — 페르소나 5 정태호(자체 구축 회의론자)와 구조적으로 유사하다. "우리도 만들 수 있다"에 대한 반론으로 쓸 수 있다.

**5. 고객별 원가 불투명 → 가격 책정 의사결정 마비**
"고객 원가 모르고 가격 정했다", "마진이 눌리는 게 보이는데 어떻게 올려야 할지 모르겠다"는 발언은 COGS attribution이 단순한 IT 운영 문제가 아니라 **BM 의사결정 문제**라는 것을 보여준다. 이는 "COGS 설명 능력 = 비즈니스 판단력"으로 가치를 재정의하는 Kyber 포지셔닝의 정당성을 실제 발화로 뒷받침한다.

### 후속 액션

1. **실제 인터뷰 전 확인 사항:** 법률 AI / 의료기록 AI처럼 판례 검색·OCR 등 외부 API를 다수 묶어 쓰는 버티컬을 인터뷰 우선순위로 올릴 것 — 가설 0 생존 확률이 높은 세그먼트.
2. **피치 Villain 슬라이드 워딩 검증:** 오늘 모의 인터뷰에서 "총액은 보여도 기능·고객별 분해가 안 된다"는 발화를 직접 확인 → 실제 인터뷰에서도 같은 발화가 나오는지 확인 후 덱 적용.
3. **rate limiter 한계 = 3단 신뢰 사다리 논거:** "금액 기준 사전 차단은 어떻게 자동화하는지 몰라서 못 하고 있다"는 발언 → Option C의 1단(리포트) → 2단(정책) 진입 가능성 시사. 후속 인터뷰에서 "경로 밖 리포트라면 먼저 볼 의향이 있는가" 추가 검증 필요.
4. **소개 경로:** 의료기록 AI CTO 1명 소개 약속 → 실제 인터뷰 전환 여부 추적.
5. **가설 0 판정식 집계:** 이번 모의 인터뷰를 생존 1건으로 카운트 — 실제 인터뷰 5건 이상 확보 후 판정(3건+ 생존 시 가설 0 채택).
