## 내가 던진 질문 (요지)

> "라이너처럼 검색·크롤링·리랭킹 다중 호출이 발생하는 구조는 토큰 외에 **외부 API 비용 추적이 가장 까다로울 것**이라는 가설을 세웠는데, 실제 현업에서도 그런지 궁금하다."

## 답변 (원문 보존 — 개인 서명만 삭제)

핵심을 정리하면:

1. **인덱싱 구축 비용 ≠ 운영 비용** — "검색을 위한 인덱싱 구축에 드는 비용과, 그 엔진을 활용해 실제 운영에서 발생하는 비용은 종류가 다르다."
2. **크롤링** = 검색 엔진에 쓸 인덱싱 데이터를 구축하는 비용. **사용자 수·상황과 무관하게 수집 로직에 따라 발생**한다.
3. **검색·리랭킹 (자체 구축 시)** = "한 대의 서버가 감당할 수 있는 요청 수를 기준으로 산정해볼 수 있다." 리랭킹은 필요에 따라 **서버를 따로 두고 운영**할 수 있고, 이때 드는 비용은 검색 비용과 **별개**가 된다.
4. **외부 검색 API를 쓰는 경우 (질문의 "토큰 외 외부 API"를 이 케이스로 해석)** — 내부 구조가 다르게 동작한다. **크롤링은 필요 없고 검색만 남으며, 보통 토큰이 아니라 검색 요청 단위로 과금**된다.
5. **리랭킹을 API로 제공하는 회사도 있을 수 있지만, 그렇게 하려면 검색 결과를 해당 서비스로 전송해야 한다.**

> (원문 전체·서명은 로컬 보관. 위는 문단 순서·표현을 최대한 보존한 요지.)

## 시사점

- **최대 교훈(Mom Test):** 나는 "가설이 맞냐"를 직접 물었고, 상대는 예의 바르게 **의견/메커니즘**으로 답했다 → pain·행동 데이터는 0. 다음 접점은 반드시 **과거 행동·구체 사건**으로 물어야 한다.
- **부분 반증을 정직하게 기록:** "다중 호출 = 추적 가장 까다로움"은 이 엔지니어에겐 자명하지 않았다. 추적이 어려운 게 아니라 **"기능·팀·고객별로 귀속(attribution)"** 하는 순간이 어려운지가 진짜 질문 — 이건 아직 안 물어봤다.
- **build/buy가 비용 구조의 1차 분기라는 현업 확인** → `_START_HERE.md` ❓ "Korea Build→Buy threshold" 검증의 진입점으로 이 대화를 사용.
- 라이너는 여전히 **무료 디자인 파트너** 후보로 유효. 상대가 성실히 답해줬으니 **후속 1회 더** 시도할 자산 있음.

## 후속 질문 (Mom Test — 과거 행동·구체 사건 중심, 우선순위 순)

> 원칙: 우리 가설을 다시 검증받지 말 것. 상대의 **실제 과거 행동**과 **누가 그 숫자를 궁금해하는지**를 캘 것. 링크드인 비동기라 1~2개만 골라 짧게.

1. **[Build/Buy — 최우선]** "말씀 중 자체 구축과 외부 검색 API가 구조를 가른다고 하셨는데, 라이너는 현재 검색·리랭킹을 자체 엔진으로 운영하시나요, 외부 API를 쓰시나요? 그 결정을 **언제·어떤 계기로** 내리셨는지 궁금합니다." → 한국 Build→Buy 임계 + 현 상태 동시 확보.

2. **[귀속 행동 — 진짜 pain 테스트]** "월말에 '이번 달 검색+리랭킹+크롤링에 총 얼마 썼는지', 나아가 '**기능/팀/고객별로 각각 얼마인지**'를 실제로 뽑아보신 적 있나요? 있었다면 **어떻게** 뽑으셨고 시간이 얼마나 걸렸나요?" → 추적이 아니라 attribution이 아픈지, 과거 행동으로 확인.

3. **[누가 궁금해하나 — COGS 수요]** "그 숫자를 조직 안에서 궁금해하는 사람이 있나요? 재무나 경영진이 '고객 1명/쿼리 1건당 원가'를 물어본 적이 최근에 있었는지." → 우리 핵심 가치(단위 원가 설명 수요)의 존재 여부.

4. **[비결정 워크로드 — 차별화 검증]** "에이전트가 예상보다 검색/툴 콜을 많이 돌려서 **비용이 튄 적**이 있나요? 있었다면 그걸 **언제·어떻게 알아차리셨는지**." → Semantic ROI Kill-switch 차별화 근거 + 비결정 워크로드 비용 스파이크.

5. **[상대 답변 되받기 — 추정 vs 실제]** "요청당 원가를 서버 용량 기준으로 산정 가능하다고 하셨는데, 실제 청구서가 그 산정을 **크게 벗어난 달**은 없었나요?" → "추정 가능"이 진짜인지 낙관인지.

> 추천: 상대가 성실했으니 **1번 + 2번만** 먼저 보내 부담을 낮춘다. 반응 좋으면 3~5번을 다음 라운드로.
