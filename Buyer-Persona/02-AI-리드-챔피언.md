# Buyer Persona 2: AI Operations Lead / 디지털 전환 담당자 — 챔피언 (Champion)

> ⚠️ 상태: 검증되지 않은 가설. 2026-08-03 ICP 2차 재설정(AI-native → 비 AI-native 중견기업) 반영.
> 구 버전(AI 엔지니어 리드, AI-native 스타트업)은 페르소나 성격이 근본적으로 달라 전면 재작성.

---

## 프로필

| 항목 | 내용 (가설) |
|---|---|
| 역할 | AI Operations Manager, 디지털 전환 담당자, 데이터 엔지니어, 또는 "AI 도구 담당자". 회사에서 AI 벤더 계정·청구서를 실무로 관리하는 사람 |
| 산업 | 운송·물류, 제조, 금융서비스, 리테일 등 비 AI-native 중견기업 |
| 배경 | IT 운영·데이터·비즈니스 분석 경력. AI를 직접 개발하지 않고 **AI SaaS 도구를 도입·운영·관리**하는 역할. "코드는 안 짜지만 5개 AI 대시보드에는 매일 들어간다" |
| 권한 | 소규모 AI 도구 도입은 재량 가능. 예산이 큰 계약이나 벤더 추가는 IT Director/CTO 승인 필요 |
| 일상 | 매월 말 각 AI 벤더 대시보드를 돌며 사용량·비용을 스프레드시트에 모아 IT Director에게 보고. 벤더 청구서 이상이 있으면 지원팀에 문의. 새로운 AI 도구 평가 요청이 자주 들어옴 |

---

## 목표 (성공 기준)

- 월말 AI 비용 집계 작업 시간을 줄이는 것 (현재 2~3일 → 수분)
- IT Director가 "AI 비용 얼마야?"를 물을 때 즉시 답할 수 있는 것
- AI 벤더가 늘어나도 관리 복잡도가 비례해서 늘지 않는 것
- 새 AI 도구 도입 전에 예상 비용을 미리 알 수 있는 것

---

## Pain Points

1. **월말 수동 집계 지옥.** AI 벤더마다 다른 대시보드, 다른 날짜 기준, 다른 단위(토큰/API콜/좌석/요청 수). 이걸 스프레드시트에 합산하는 데 2~3일 소요. 벤더가 하나 늘면 이 작업이 더 복잡해짐.
2. **청구서 단위가 달라 비교 불가.** LLM API는 토큰당, CS AI는 대화당, 문서 처리는 페이지당, 수요 예측 SaaS는 월정액. 이걸 "프로젝트당 얼마 썼나"로 변환하는 수식이 깨지기 쉬움. 벤더가 가격 정책 바꾸면 스프레드시트 전체 수정 필요.
3. **어디서 비용이 튀었는지 모른다.** 이번 달 AI 비용이 전월 대비 30% 늘었는데, 어느 벤더의 어떤 기능이 원인인지 파악하려면 각 대시보드를 하나씩 뒤져야 함.
4. **새 도구 비용 예측 불가.** AI 도구 도입 전 "이거 한 달에 얼마 나올까?"를 추정하기 위해 유사 사례를 찾거나 벤더 영업팀 추정에 의존. 실제 청구와 다른 경우 많음.
5. **부서별 사용량 분리 불가.** "물류팀 AI 비용 vs 고객서비스팀 AI 비용"을 나눠달라는 요청이 오면 벤더 데이터 구조상 불가능해 추정치로 답함.

## 도입 트리거 (가설 — 인터뷰로 검증)

| 트리거 | 상황 |
|---|---|
| **월말 청구서 집계 스트레스** | 이번 달도 2~3일 썼을 때 "이걸 자동화할 수 없나" 검색 시작 |
| **IT Director 보고 요청** | "AI 예산 현황 한 페이지로 정리해줘" 요청 받을 때 |
| **벤더 추가 시점** | 이미 관리하는 AI 벤더가 4개인데 하나 더 추가 결정됐을 때 |
| **AI 비용 이상 탐지** | 전월 대비 청구액이 크게 늘었는데 원인 파악에 반나절 이상 소모될 때 |
| **새 AI 도구 예산 요청** | 도입 전 비용 예측을 위해 현재 사용 패턴 데이터가 필요할 때 |

## 도입 장벽 (예상 반론)

| 반론 | 대응 방향 |
|---|---|
| "스프레드시트로 지금도 하고 있어요" | 벤더 단가 변경·신규 벤더 추가 시 스프레드시트가 깨짐 = 유지보수 비용이 계속 발생 |
| "벤더마다 API 연동이 복잡할 것 같아요" | 신뢰 사다리 1단: 청구서 CSV/PDF 업로드만으로 시작 가능 — 연동 없이 리포팅부터 |
| "우리 IT Director가 승인해줄지 모르겠어요" | 챔피언이 먼저 써보고 월말 집계 시간 감소를 수치화 → IT Director 설득 자료 생성 |
| "비용이 얼마인지" | 월말 집계 2~3일 × 인건비 vs 툴 비용 비교로 ROI 명확 |

## 두 페르소나 관계 (영업 가설)

- **진입:** 챔피언(이 페르소나)이 무료/저비용 티어로 먼저 써보고 월말 집계 시간 감소를 직접 체감 → IT Director에게 유료 전환 제안 + CFO 보고 자동화 데모
- **메시지 분리:** 챔피언 = "내 월말 집계 2~3일이 줄어든다" / IT Director = "CFO에게 AI 비용 보고가 가능해진다" / CFO = "AI 투자 ROI를 부서·프로젝트 단위로 설명할 수 있다"
- **인터뷰 확인 포인트:** 이 역할이 비 AI-native 중견기업에 실제로 존재하는가? 아니면 IT Director가 이 역할도 겸하는가? (겸직 시 페르소나 통합 검토)

## 인터뷰 검증 포인트

1. 현재 AI 벤더 청구서를 어떻게 집계하나? 얼마나 걸리나? 누가 하나?
2. 가장 힘든 순간이 언제인가? (월말 집계? 비용 이상 탐지? 보고서 작성?)
3. 이 문제를 해결하기 위해 시도해봤던 것이 있나? 왜 안 됐나?
4. 새 AI 도구를 도입할 때 비용 예측을 어떻게 하나?
5. IT Director/CFO가 AI 비용 관련해서 어떤 걸 가장 자주 물어보나?
