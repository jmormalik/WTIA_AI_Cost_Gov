# ICP: 유료 타겟 = 중간 시장/스케일업 · 한국 AI 스타트업 = 무료 디자인 파트너

> ⚠️ 상태: 검증되지 않은 가설. 인터뷰로 확인된 사실 아님 (정식 인터뷰 0건).
>
> 결정 기록:
> - 2026-07-20: 한국 AI 네이티브 스타트업을 1차 타겟으로 확정 (구버전).
> - **2026-07-22: ICP 재설정** — 유료 타겟을 소규모 스타트업 → **중간 시장/스케일업**으로 전환. 근거: 포지셔닝 재설정 (죽음의 계곡: 소규모는 ROI 음수, 대기업은 자체구축). 한국 AI 스타트업 → 무료 디자인 파트너로 변경.
> - **2026-08-03: ICP 재설정 2차** — 유료 타겟을 AI-native 스케일업 → **비 AI-native 중견기업 (AX 전환 중, 멀티 기능 롤아웃 단계)**으로 전환. 근거: 멘토링 세션 — ① AI-native는 자체구축이 쉽고 익숙함 ② 비 AI-native 기업 수가 압도적으로 많아 시장 규모 ↑ ③ 멀티 프로바이더/툴 사용 현실 → 멀티 플랫폼 비용 애그리게이터로 포지션 재정의. 초기 니치 = 운송/물류(AX 도입 속도 빠름, 멀티 API 복잡도 높음). 조건: 월 AI 지출 $100K+ AND 3개+ AI 플랫폼/벤더 동시 운영.

## 1. 유료 타겟 — 비 AI-native 중견기업 (AX 전환 중, 멀티 기능 롤아웃 단계)

**정의:** AI가 본업이 아니지만, 운영 여러 기능(라우팅·CS 자동화·문서 처리·수요 예측 등)에 AI 에이전트를 이미 배치해 실비 청구가 시작된 중견기업. **AI 엔지니어링 DNA가 없어 자체 비용 거버넌스 툴을 만들 수 없고, 스타트업보다 지출·감사 압박은 큰 회사.** ← 핵심 판별 기준

초기 니치(wedge): **운송·물류** — AI 라우팅 + CS 봇 + 문서 자동화 + 수요 예측을 동시에 운영, 멀티 API 벤더 복잡도가 특히 높음. (2026 AI in Logistics 시장 $21~26B, BRC/DataM 추정)

이 세그먼트를 유료 타겟으로 고른 이유:

- **"직접 만든다" 반론이 구조적으로 소멸한다.** AI-native는 자체구축이 가능·선호 → 비 AI-native는 AI 엔지니어링 조직 자체가 없어 **사는 것 외에 선택지가 없다.**
- **비 AI-native 기업 수가 AI-native보다 압도적으로 많다** → 시장 모집단이 크다.
- **멀티 플랫폼 복잡도가 더 크다.** 비 AI-native는 AI를 내부 구축 대신 외부 벤더로 조합 → 3개+ 플랫폼 동시 운영, 청구 주기·단가·API 형태 전부 다름 = 비용 파편화 pain이 구조적.
- **월 $100K+ 지출에서 ACV $30K = take-rate 2.5%** → ROI 방어 가능. (McKinsey 2025: "전사 롤아웃" 단계 기업 $50K~$200K+/월, Deloitte 2025)
- **재무·감사 압박이 실재한다.** AI를 도입한 이상 이사회·CFO가 AI 원가 COGS 설명을 요구하기 시작함 — 절감이 아니라 **설명이 상시 니즈**.

### 프로필 (Firmographics + AI 사용 형태)

| 축 | 기준 (가설) |
|---|---|
| 산업 | **비 AI-native** — AI가 본업이 아닌 전통 산업 (운송·물류·제조·금융·리테일 등). AI 자체를 파는 회사 아님 |
| 규모 | 팀 200~2,000명, 중견기업 (시리즈 C+ 또는 매출 발생 비스타트업) |
| 월 AI 지출 | **$100K+**, 실비 청구 단계. AI를 여러 기능에 걸쳐 이미 운영 중 (파일럿 아님) |
| AI 벤더 수 | **3개 이상** AI 플랫폼/SaaS/API 동시 운영 — 청구 주기·단가 체계가 각각 다름 |
| AI 사용 형태 | 에이전트/자동화가 **프로덕션 운영 코어**에 붙음. 고객 CS·문서 처리·라우팅·예측 중 2개 이상 기능에 AI 배치 |
| 스택 | 서드파티 모델 + 서드파티 SaaS 조합. 자체 AI 개발 없음. 멀티 프로바이더면 강한 신호 |
| 조직 신호 | CFO/재무팀이 AI 예산 통제 요구 시작. IT 또는 운영팀이 AI 벤더 청구서 통합 관리 담당 중 |

### 관찰 가능한 시그널 (후보 발굴용)

- 채용공고에 **AI 자동화·RPA·AI 운영** 포지션 (AI 개발직 아님 — 도입·운영 역할이 신호)
- "AI 도입 성과" 보도자료 또는 컨퍼런스 발표 (파일럿 완료 → 전사 확장 단계 판별)
- 3개 이상의 AI 벤더 파트너십·통합 언급 (Microsoft Azure AI + OpenAI + 버티컬 AI SaaS 동시 사용 등)
- 재무 보고서 또는 IR에 "AI 투자" 항목 별도 기재 시작
- IT 팀이 AI 벤더 청구서를 수작업으로 통합하는 포지션 채용 (운영 복잡도 신호)
- 운송·물류: AI 라우팅(route optimization) + CS AI + 서드파티 물류 API 동시 계약 흔적

## 2. 무료 디자인 파트너 — 한국 AI 네이티브 스타트업

**역할:** 유료 시장이 아니다. ① 가설 0·가설 1 검증(툴/외부API 비중, COGS 상시 니즈) ② 샘플 로그 확보(Cost Autopsy) ③ 덱 트랙션 대용("디자인 파트너 N곳") — 접근성·의사결정 속도가 빠른 검증 채널. 피치 시장 스토리 = **"한국 = 쐐기, 시장 = 글로벌 에이전트 인프라."**

**정의:** LLM 기반 에이전트/AI 기능이 제품의 핵심 가치인 한국 스타트업. AI를 "도입"한 회사가 아니라 AI가 곧 제품인 회사.

| 축 | 기준 (가설) |
|---|---|
| 규모 | 팀 10~100명, 시드~시리즈 B. 엔지니어 5명 이상 (자체 개발 조직 보유) |
| 산업 | 제품에 에이전트를 내장한 B2B/B2C SaaS — AI 검색·리서치, AI CS, 업무자동화, 버티컬 에이전트(법률·의료·커머스 등) |
| AI 사용 형태 | 에이전트가 프로덕션에서 고객 트래픽을 받는다 (파일럿·데모 아님). 멀티스텝 툴 콜이 응답 경로에 포함 |
| AI 지출 | 월 ~$5K+ 또는 **하이퍼스케일러 크레딧 지출 중, 6개월 내 소진 예정** |
| 스택 | 멀티 프로바이더 또는 멀티 모델. LiteLLM/Langfuse류를 쓰거나 검토 중이면 강한 신호 |

**타이밍 트리거 (가설):** 크레딧이 소진되어 실비 청구가 시작되는 시점에 비용 추적·통제 pain이 급증 — 이 시점의 회사가 최적 접촉 대상.

**발굴 시그널:** 제품 페이지의 "AI 에이전트"·자율 수행 문구, LLM Ops 채용공고, 비용 최적화 기술 블로그, 하이퍼스케일러 크레딧 프로그램(Bedrock/Azure/GCP) 수혜 이력. 후보 풀: AIIA AI 에이전트 분야, Google for Startups AI First Korea, AWS 유니콘데이 참가사 (상세: [../Interview/인터뷰-후보-리스트.md](../Interview/인터뷰-후보-리스트.md)).

> ⚠️ 미해결 (팀 확인 대기): 인터뷰 스크리닝 필수 조건(매출 주원천 = 유료/B2B)이 "한국 스타트업 = 무료 디자인 파트너" 전략과 충돌하는지 — 유료 검증용 표본과 디자인 파트너 후보를 같은 파이프라인에서 다르게 태깅할지 결정 필요.

## 3. Anti-ICP (제외 기준)

| 제외 대상 | 이유 |
|---|---|
| 월 AI 지출 $5K 미만 또는 파일럿·실험 단계 기업 | 프로덕션 트래픽이 없어 pain 미발생. 지출 임계 미달 → ROI 음수 |
| AI 벤더/플랫폼 1~2개만 사용하는 기업 | 비용 파편화 pain이 약함. 단일 청구서로 관리 가능 |
| **AI-native 스타트업/스케일업** | 자체구축이 가능하고 선호함. "LiteLLM 쓰면 되잖아요" 반론이 실제로 성립 |
| 대기업 (AI 엔지니어 수백 명 이상) | Meta·Uber처럼 직접 만든다 — 구매 안 함 |
| 단순 챗봇/단일 LLM 호출 (툴 콜 없음) | 멀티 플랫폼 복잡도가 발생하지 않음. 비용이 예측 가능 |
| 자체 파운데이션 모델 개발사 | 비용 구조가 API 호출이 아니라 GPU 인프라 — 다른 문제 |
| SI/외주 에이전시 | 비용 부담 주체가 고객사라 pain 소유자가 아님 |
| AX 전환 검토 단계 기업 (파일럿 미완, 프로덕션 미도달) | 아직 지출 임계 미달. **재접촉 시점 = AI가 운영 코어에 배치된 후** |

## 4. 의사결정자 (Buyer Persona 연결)

- **1차 접촉(챔피언):** AI/데이터 리드, IT 운영 리드 — 벤더 청구서 통합 고통을 직접 겪는 실무자 ([../Buyer-Persona/02-AI-리드-챔피언.md](../Buyer-Persona/02-AI-리드-챔피언.md))
- **경제적 구매자:** CTO 또는 IT 디렉터 — AI 투자 ROI·COGS 보고 책임자
- **영향자:** CFO/재무 — AI 예산 통제 요구가 구매 트리거 역할
- ⚠️ 비 AI-native에서는 CTO가 AI 전문성이 낮을 수 있음 → 챔피언(실무 AI/IT 리드)이 먼저 내부 설득을 해야 하는 bottom-up 패턴 가능성. 페르소나 업데이트 필요.

## 5. 인터뷰 스크리닝 질문

ICP 부합 여부를 5분 안에 거르는 질문 (상세 문항은 [../Interview/인터뷰-가이드-Mom-Test.md](../Interview/인터뷰-가이드-Mom-Test.md) §4-2 가설 0·1 문항 참조):

0. "AI나 자동화 관련해서 지금 몇 개 플랫폼·벤더를 동시에 쓰고 있나요?" — **멀티 플랫폼 여부 (ICP 1차 필터). 2개 이하면 5분 탈락 검토**
1. "AI 자동화가 지금 실제 운영에 들어가 있나요, 아니면 아직 파일럿 단계인가요?" — 프로덕션 배치 여부
2. "각 플랫폼 청구서를 누가 어떻게 통합하고 있나요? 한 화면에서 전체를 보는 방법이 있나요?" — **비용 파편화 pain (가설 0 대체)**
3. "월 AI 관련 지출이 대략 어느 규모인가요? (모든 플랫폼 합산)" — 지출 규모 (유료 타겟 판별: $100K+)
4. "CFO나 재무팀이 AI 비용 관련해서 보고나 설명을 요청한 적 있나요?" — **COGS 설명 니즈 (가설 1)**
5. "AI 비용이 예상보다 크게 나왔을 때 어디서 왔는지 추적해본 적 있나요? 어떻게 했나요?" — status quo 행동 확인
6. "이걸 자체적으로 통합할 IT/엔지니어 리소스가 있나요, 아니면 외부 툴을 찾고 있나요?" — 구매 vs 자체구축 (비 AI-native는 거의 구매 선호 예상)

## 6. 후순위 세그먼트 (보류 기록)

- **(b) 엔터프라이즈 내부 에이전트 도입 기업** — 비용 귀속·감사 요구는 강하나 조달 사이클이 길다. 중간 시장 검증 후 업마켓 경로로 재평가
- **(c) 멀티테넌트 에이전트 플랫폼 운영사** — 테넌트별 예산 격리 니즈가 기술적으로 가장 절실. SatGate가 노리는 타겟과 겹침. 중간 시장 안의 서브세그먼트로 흡수 가능성

## 7. ICP 전환 트리거 — 어떤 데이터가 나오면 다시 바꾸는가

> 목적: 전환 결정을 감이 아니라 사전에 합의된 기준으로 하기 위함. 2026-07-21 최초 작성(스타트업→미드마켓 트리거), **2026-07-22 재설정으로 트리거 1이 데이터 축적 전에 논리 근거로 선제 발동됨** — 따라서 신 트리거는 역방향(미드마켓 가설이 틀렸을 때)을 감시한다.

**전환/수정을 검토하는 조건 (인터뷰 5~10건 축적 후 판정):**

| # | 트리거 | 측정 방법 | 대응 방향 |
|---|---|---|---|
| 1 | 중간 시장도 "직접 만든다"로 일관 | "구매 vs 자체구축" 질문에서 5건 이상 연속 자체구축(또는 OSS 조합으로 충분) 응답 | 죽음의 계곡이 중간 시장까지 확장 — 포지셔닝 자체 재검토 (경로 밖 리포트 단독 상품화 등) |
| 2 | COGS 귀속이 상시 니즈가 아님 (가설 1 기각) | 가설 1 판정식: 5건+ 생존 / 3건− 기각 (인터뷰 가이드 참조) | 가치 프레임 재설계 — Semantic ROI Kill-switch 등 대안 전면화 |
| 3 | 중간 시장 접근 실패 (응답률 붕괴) | 미국 중간 시장 아웃리치 10곳+ 무응답, 한국 디자인 파트너만 응답 | 검증 채널을 한국에 집중, 미국은 2차 자료·자문 경유로 우회 |
| 4 | 크레딧 트리거 가설 기각 | 크레딧 소진 시점과 pain 강도가 무상관으로 판명 | 디자인 파트너 발굴 wedge만 폐기 — ICP는 유지 |
| 5 | 챔피언 경로 부재 | CTO/AI 리드 분리 구도 확인 안 되고 도입 결정이 전부 top-down | 페르소나 통합 + 영업 모델 수정 — ICP는 유지 |

**전환하지 않는 조건 (노이즈로 취급):**

- 인터뷰 1~2건의 부정 신호 — 표본 부족. 최소 5건 후 판정
- "엔터프라이즈가 돈이 더 많다"는 일반론 — 데이터 아님
- 경쟁사(SatGate 등)의 행보 — 그들의 선택이지 우리 데이터가 아님

## 8. 검증 계획
